# 🎓 Userscripts for NCUT

專為國立勤益科技大學 (NCUT) 校園資訊系統打造的使用者腳本集合，改善操作體驗並提升學習效率。

---

## 📦 腳本列表

| 腳本名稱 | 適用平台 | 功能重點 | 安裝 |
| :--- | :--- | :--- | :---: |
| **NCUT SSO Bookmark** | 勤益單一入口 (SSO) | 選單 ★ 收藏常用功能，儀表板首頁捷徑卡片 (支援拖曳排序) | [📥 安裝](https://raw.githubusercontent.com/xydesu/userscript-for-ncut/main/NCUT%20SSO%20Bookmark.user.js) |

| **NCUT NMSD Auto Redirect** | 勤益入口網 (NMSD) | 訪問首頁秒速自動跳轉至 wbcmss 系統，告別多餘點擊 | [📥 安裝](https://raw.githubusercontent.com/xydesu/userscript-for-ncut/main/NCUT%20NMSD%20Auto%20Redirect.user.js) |

## 🚀 快速開始

1. **安裝外掛**：請先安裝瀏覽器擴充套件 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. **安裝腳本**：點擊上方表格中對應腳本的「📥 安裝」連結。
3. **完成安裝**：在跳出的管理器視窗中點選「安裝」即可生效。

---

## 💡 使用重點

* **NCUT SSO Bookmark**：進入學生專區點擊星號（★）收藏常用項目；首頁儀表板卡片可直接點擊進入，亦支援滑鼠拖曳排序。
* **NCUT e-learn 萬用工具箱**：進入「全校課程」後，點擊頂部導航列的「⚙️ 腳本設定」按鈕，即可自由開啟或關閉各模組功能。
* **NCUT NMSD Auto Redirect**：直接造訪首頁時自動觸發跳轉，無需額外手動設定。
